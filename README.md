Feather Code의 첫 공개 버전입니다. 가볍고 빠른 Windows용 코드 편집기로, 로컬 파일과 FTP/SFTP 서버 파일을 한 창에서 편집할 수 있습니다.

## 주요 기능

**편집기**
- 40여 개 언어 문법 강조 (PHP·Blade, JS/TS·JSX/TSX, Vue, Svelte, Python, Rust, Go, SQL, Markdown, JSON, YAML, Dockerfile, nginx 등)
- 코드 접기, 괄호 짝 표시, 들여쓰기 안내선, 미니맵
- 멀티 커서 (Alt+클릭, Ctrl+D, Ctrl+Shift+L, Ctrl+Alt+↑/↓)
- 찾기·바꾸기(정규식), 폴더 전체 찾기, 파일 이름으로 바로 열기(Shift 두 번)
- 언어 서버(LSP) 연결: 자동 완성, 오류·경고 표시, 정의로 이동 (설정에서 바로 설치)
- Markdown 나란히 미리보기, JSON 트리 보기
- 10MB가 넘는 로그도 바로 열기 (줄 단위 편집, 끝 따라가기)

**서버·터미널**

**편집기**
- 40여 개 언어 문법 강조 (PHP·Blade, JS/TS·JSX/TSX, Vue, Svelte, Python, Rust, Go, SQL, Markdown, JSON, YAML, Dockerfile, nginx 등)
- 코드 접기, 괄호 짝 표시, 들여쓰기 안내선, 미니맵
- 멀티 커서 (Alt+클릭, Ctrl+D, Ctrl+Shift+L, Ctrl+Alt+↑/↓)
- 찾기·바꾸기(정규식), 폴더 전체 찾기, 파일 이름으로 바로 열기(Shift 두 번)
- 언어 서버(LSP) 연결: 자동 완성, 오류·경고 표시, 정의로 이동 (설정에서 바로 설치)
- Markdown 나란히 미리보기, JSON 트리 보기
- 10MB가 넘는 로그도 바로 열기 (줄 단위 편집, 끝 따라가기)

**서버·터미널**
- FTP / FTPS / SFTP 연결, 서버 파일 바로 편집·저장
- 로컬 폴더 ↔ 서버 폴더 매핑과 파일 비교
- 내장 터미널: SSH, PowerShell, Git Bash, cmd
- 서버 로그 실시간 모니터링 (tail -f), 텍스트 추출

**작업 흐름**
- Git 변경 표시와 Git 패널
- 세션 복원: 다시 켜면 열려 있던 파일 그대로, 저장 안 한 내용은 자동 백업에서
- 클립보드 기록 (Ctrl+Shift+C / Ctrl+Shift+V)
- 탐색기 우클릭 "Feather Code로 열기", 파일 연결
- 한국어 · English · 日本語 · 中文

## 설치
1. 아래 `FeatherCode-0.1.0-setup.exe`를 받아 실행합니다. 관리자 권한은 필요 없습니다.
2. 다음 버전부터는 앱이 자동으로 업데이트를 알려 줍니다 (도움말 > 업데이트 확인).

> 처음 실행할 때 Windows SmartScreen이 "Windows의 PC 보호" 경고를 띄우면 **추가 정보 → 실행**을 누르세요.

**지원 환경:** Windows 10 / 11 (64비트)
